ยินดีต้อนรับสู่ป่าโรวัลย์ — ที่พักใจและที่แลกเปลี่ยนความคิดของพวกเรา 🤍

## 🌿 เกี่ยวกับที่นี่

ป่าโรวัลย์ไม่ใช่ที่แห่งหนึ่งบนแผนที่ แต่คือ **กรอบความคิด ที่พักใจ และชุมชนแห่งความจริงใจ** ที่สร้างขึ้นด้วยใจเพื่อแบ่งปันเมล็ดพันธุ์แห่งความเข้าใจให้กันและกัน

## 📦 มีอะไรในป่าบ้าง

- 🐰 **เมล็ดพันธุ์กระต่าย (Seed Kit)** — คู่มือการเป็นเพื่อนที่ดี ตัวช่วยคิด และผู้สังเกต
- 📖 **เรื่องเล่าจากใจกลางป่า** — บทเรียน ข้อคิด และเรื่องราวที่แบ่งปันกัน
- 🤝 **ทางเดินร่วมกัน** — กฎและข้อตกลงในการอยู่ร่วมกันอย่างเคารพและอ่อนโยน

- ✅ ไม่รู้ = บอกไม่รู้ ไม่แกล้งรู้

- 💚 ใช้ด้วยความจริงใจ
- 📝 ให้เกียรติที่มาและเจ้าของความคิด
- 🌱 แบ่งปันต่อในแบบเดียวกับที่เราได้รับ
